Trichr-o-matic Web · Quick Tour

Welcome to Trichr-o-matic

Trichr-o-matic is an app designed for trichrome photography.
From three black and white shots to the recomposed color image, its complete set of tools keeps every step simple: import, align, edit and export your photos with ease.

Start the tour to learn more.

Load 3 photos

Drop the files on the preview, or import them in the Files tool. Drag a row's grip onto another to swap two channels.Tap Import 3 photos on the preview, or import them in the Files tool.

Classic Trichrome is for black and white shots, Color Trichrome takes each channel's own color from color shots to create a Harris Shutter effect.

Align the channels

Auto align lines up the red and blue channels on the green one. Each channel's tab then lets you fine-tune its Light, Position and Geometry.

Drag directly on the preview with Move on Canvas or Stretch on Canvas.

Finish and export

Color grade the recomposed image with Curves. Working from a negative scan? The Negative button inverts it. Then reframe the photo as you like with Crop.

Export saves the final image at full resolution.

Gestures on the photo

Tap: full screen
Double tap: fit / 1:1
Pinch: zoom
Press and hold: compare with the original

In the tools, tap the active tab to hide them and enlarge the preview.

Download

macOS 12 Monterey or later · Windows 10 or 11 (64-bit)

First launch on Mac

  1. Unzip the file and move Trichr-o-matic to your Applications folder.
  2. Open it: macOS blocks it once, since the app isn't signed yet. Click Done.
  3. In System Settings ▸ Privacy & Security, click Open Anyway, then Open.

If macOS says the app “is damaged”, run this in Terminal, then open it again:

xattr -cr /Applications/Trichr-o-matic.app
Full instructions

First launch on Windows

  1. Run the installer. No administrator password is needed.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway. The installer isn't signed yet, so Windows doesn't recognize it.
